# GSAT 단순암기 v1.5

## 추가된 기능
- **나누기**: 정확하게 나누어떨어지는 나눗셈, 기본(2~12)·심화(11~25)·혼합 난이도.
- **백분율 역산**: "전체의 15%가 54"일 때 전체 값 구하기. 4지선다 또는 직접 입력.
- **분수 크기 비교**: 분수 2개를 비교해 `<`, `=`, `>` 중 선택. 정수 교차곱으로 채점하며 동치분수도 포함.
- **오답 모니터링**: 홈의 `오답 모니터링` 또는 상단 `▤`에서 유형별 정답률, 누적 오답, 평균 풀이 시간, 틀린 문제 목록 확인.
- **집중 복습**: 오답 문제를 그대로 재출제, 복습에서 2회 연속 정답이면 `복습 완료`로 분류. 오답은 다시 틀리면 반복 목록으로 돌아옴.

기존 알파벳 번호, 분수 비율표 암기/문제, 분수 응용, 표 탐색, 집합 다이어그램 암기/퀴즈, 명제 추론을 유지합니다.

## 공개 배포: GitHub Pages
1. GitHub에서 새 **Public** 저장소(예: `gsat-memory`)를 생성합니다.
2. 이 ZIP을 압축 해제한 후 `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/`를 **저장소 최상위**에 업로드합니다. ZIP 파일을 그대로 업로드하면 사이트가 작동하지 않습니다.
3. 저장소 `Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save`를 선택합니다.
4. 배포된 주소 `https://깃허브아이디.github.io/gsat-memory/`를 휴대전화 브라우저에서 열어 사용합니다.
5. Chrome/Safari의 `홈 화면에 추가`를 사용하면 앱처럼 실행할 수 있습니다. PWA는 첫 방문 뒤 리소스를 캐시해 오프라인에서 재실행할 수 있습니다.

## 개인 정보·저작권
- 로그인, 광고, 분석 스크립트, 외부 API가 없습니다. 답안 기록은 브라우저 `localStorage`에 저장됩니다. 서버나 GitHub로 전송하지 않습니다.
- 저장된 데이터는 브라우저·기기별로 별도이며, 브라우저 기록 삭제 또는 다른 기기 사용 시 자동 이전되지 않습니다.
- 기존 v1.4와 **동일한 사이트 주소 및 브라우저**에서 업데이트하면 기존 누적 기록을 이어받습니다. `file://` 파일 위치나 사이트 주소가 달라지면 저장 공간이 다를 수 있습니다. 게임별 상세 정답률과 오답 목록은 v1.5 이후의 풀이부터 누적됩니다.
- 문제·수치·표는 독자적으로 생성합니다. 상용 GSAT 교재 문제·그림·선지 원문을 허락 없이 업로드하지 마세요.
- 삼성 또는 GSAT 운영기관과 제휴하지 않은 **비공식 교육용 게임**입니다.
- GitHub Pages는 정적 교육·프로젝트 사이트에 적합하며, 상업적 SaaS의 무료 호스팅용으로 사용할 수 없습니다. 최신 약관을 확인하세요.

## 파일
`index.html`: Pages 시작 파일, `app.js`: 게임 로직 및 확장 등록, `styles.css`: 테마, `sw.js`: 오프라인 캐시, `manifest.webmanifest` 및 `icons/`: 모바일 설치 정보. `GSAT_단순암기_v1.5_바로실행.html`: 단독 실행 파일(배포에는 불필요).

## 개발 시 주의
- 질문 생성/화면/판정은 `registerMode({...})`로 등록합니다.
- 확장 모드에도 오답 기록 자동 저장이 적용됩니다. 단, JSON으로 직렬화 가능한 질문 데이터만 저장하세요.
- 문제 식별이 중요한 확장 모드는 `questionIdentity`에 고유 규칙을 추가하면 좋습니다.
