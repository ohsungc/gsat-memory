# GSAT 단순암기 v2.1 — 흑백 미니 메모 그림판 포함

개인 학습용 정적 웹앱 (HTML/CSS/JavaScript). 로그인, 서버, 별도 설치 프로그램이 필요 없습니다.

## v2.1 보완: 흑백 미니 메모 그림판

- **도식 추리, 조건·논리 추리, 집합 추론, 집합 다이어그램 퀴즈**에서 화면 오른쪽 아래 `✎ 메모` 버튼으로 열 수 있습니다.
- 검정 펜(흰 바탕), 흰 지우개, 한 단계 되돌리기, 전체 지우기, 닫기 기능을 지원합니다. `전체 지우기` 후 `되돌리기`로 복원할 수도 있습니다.
- **모바일**: 손가락·터치펜으로 캔버스에 직접 작성합니다. 그림판 안에서 필기할 때만 스크롤을 막고, 접은 뒤에는 원래 문제를 조작할 수 있습니다.
- **PC**: 마우스로 필기합니다. 그림판 상단 제목줄을 드래그하면 위치를 옮길 수 있습니다.
- **도식 추리**: 같은 공통 도식의 4문항 동안 메모 유지. 다음 공통 도식으로 넘어가면 자동 초기화.
- **조건·논리 / 집합 추론 / 다이어그램 퀴즈**: 문제 1개가 끝나면 메모 초기화.
- **일시적 메모**: 브라우저 메모리에만 보관합니다. 새로고침·페이지 종료·새 문제에서 사라집니다. 오답노트, FEVER 기록, 균형 출제 기록을 수정하지 않습니다.
- **FEVER**에서도 사용할 수 있지만, 그림판을 여는 동안 제한시간은 멈추지 않습니다.
- 새 파일: `js/core/scratchpad.js`, `css/scratchpad.css`. 기존 페이지 및 공통 엔진, 서비스워커 캐시 참조가 갱신되었습니다.

## v2.1 보완: 알파벳 역방향 훈련

- 기존 **A → 1** 문제에 더해 **1 → A** 역방향 복원 문제를 추가했습니다.
- 게임 설정에서 `알파벳 → 숫자`, `숫자 → 알파벳`, `혼합`을 선택할 수 있습니다. 기본값은 혼합 출제입니다.
- 모바일에서는 숫자 문제에 0~9 키패드, 알파벳 문제에 A~Z 키패드가 자동 등장합니다. PC에서는 입력 후 Enter로 연속 풀이할 수 있습니다.
- 두 방향의 출제 빈도와 각 방향의 알파벳 번호를 별도로 균형 보정합니다.
- 기존 오답 복습 데이터(이전 방향 미표기 문제 포함)는 그대로 사용할 수 있으며, 새 역방향 오답은 별도 기록됩니다.
- 기존 버전 번호는 `v2.1`로 유지합니다.

## v2.1 신규 기능

### 도식 추리
- 하나의 공통 도식에 **4개의 기호 규칙**이 제공됩니다. 예: `ABCD → ◆ → BADC`.
- **동일한 규칙으로 4문항을 연속 출제**합니다. 4문항을 마치면 다음 규칙 도식이 생성됩니다.
- 입력→출력과 결과→입력(역방향) 문제를 섞습니다. 숫자 네 자리와 영문 알파벳 네 자리가 번갈아 생성될 수 있습니다.
- 위치교환·원형이동·자리역순·각 문자/숫자의 ±1/±2 이동이 사용됩니다.
- 설정에서 세트당 문항 수를 10으로 지정하면 도식 게임은 도식 3세트를 완성하기 위해 **12문항**을 출제합니다. 20은 20문항, 30은 32문항입니다.

### 조건 · 논리 추리
- **좌석 배치**: 2열×4행에 A~H를 배치합니다. 선택한 사람을 좌석에 메모할 수 있습니다. '항상 참/항상 거짓' 선지.
- **순서 정하기**: 6명의 도착 순서를 추론합니다. '항상 참/항상 거짓' 선지.
- **참말·거짓말**: 4개 진술 중 참인 개수를 이용해 열쇠 소유자를 식별합니다.
- **논리 명제**: P/Q/R 명제의 함의 및 참·거짓 조건을 검토합니다.
- **확률**: 서로 다른 색 공에서 2개를 뽑는 문제. 조합을 이용해 정확한 분수로 판정합니다.
- `설정 → 조건·논리 문제 유형`에서 한 유형만 반복하거나 혼합할 수 있습니다.

**검증 로직**: 좌석은 8!=40,320개의 전체 배치, 순서는 6!=720개의 전체 배치 중 주어진 조건을 만족하는 모든 경우를 검사합니다. 선지들 중 정답은 정확히 하나만 남게 생성합니다. 확률은 정수 조합과 약분으로 계산해 반올림 오차를 회피합니다.

## GitHub Pages에 올리기

1. [GitHub 저장소](https://github.com/ohsungc/gsat-memory)에서 업데이트할 경우, ZIP의 **내부 파일과 폴더**를 저장소 루트에 업로드하세요. ZIP 파일 자체가 아니라, `index.html`, `css/`, `js/`, `sw.js` 등을 업로드해야 합니다.
2. `Settings → Pages`에서 `Deploy from a branch → main → /(root)`를 사용합니다.
3. 주소 `https://사용자이름.github.io/저장소이름/`로 실행합니다.
4. 이전 내용이 보인다면 배포가 끝났는지 확인하고 `Ctrl+Shift+R`로 새로고침합니다. 새 버전의 서비스워커 캐시 이름은 `gsat-dansunamgi-v21-scratchpad`입니다. 이전 화면이 남으면 배포 완료 후 새로고침하거나 사이트 데이터를 제외한 서비스워커 업데이트를 확인하세요.

완전한 사이트 업데이트는 **전체코드 ZIP**을, 기존 v2.0에서 바뀐 파일만 갱신할 때는 **변경파일 ZIP**을 사용하세요. 폴더 경로는 유지해야 합니다.

## 구조

- `index.html`: 진입 화면과 JS/CSS 참조
- `css/reasoning-extra.css`: 도식 및 조건추리 반응형 스타일 (v2.1 신규)
- `js/games/scheme.js`: 도식 4연계 문제 생성 및 채점 (v2.1 신규)
- `js/games/deduction.js`: 조건추리 5유형 생성 및 채점 (v2.1 신규)
- `js/core/session.js`: 도식 4문항 세트 구성, 공통 세션 엔진
- `js/core/scratchpad.js` 및 `css/scratchpad.css`: 임시 흑백 메모 그림판
- `js/core/state.js`: 설정/로컬 기록
- `js/core/progress.js`: 오답노트 식별/재출제
- `js/core/fever.js`: FEVER 점수/제한시간, 신규 게임 제한시간 추가
- `sw.js`: 오프라인 캐시
- 나머지 파일: 이전 버전의 알파벳, 분수, 나누기, 표 탐색, 집합추론, 효과음/콤보 시스템

## 시험 문제 및 저작권

이 게임의 문제·도식·숫자·규칙은 **새로 생성**합니다. 공식 삼성 시험이나 상업 교재의 문항을 그대로 재배포한 것이 아닙니다. 기출 원문, 보기, 그림을 이 프로젝트에 넣어 공개하려면 해당 자료의 이용허락을 확인해야 합니다. 삼성·GSAT 공식 서비스가 아닙니다.

## 기록

기존 `localStorage` 키 `gsat-speed-lab-v1`을 유지합니다. 원래의 오답노트, FEVER 최고 기록 및 출제 분포는 삭제하지 않습니다. 새 게임도 같은 브라우저에서 기록됩니다. 다른 기기에서는 자동으로 동기화되지 않습니다.

## 메모 그림판 테스트

Chromium 320px·390px·1280px에서 터치/마우스 필기, 도구 전환, 지우개, 되돌리기, 전체 지우기 및 복구, 도식 4문항 간 유지/새 도식 초기화, 조건추리 새 문제 초기화, 일반 암기 문제에서 메모 버튼 숨김, PC 패널 드래그, 가로 넘침 여부를 검사했습니다. 실제 모바일 기기에서의 터치감은 별도 실사용 확인이 필요합니다.

## 기술 테스트

Chromium 자동화: 320/390/1280 px 세 가지 화면에서 화면 가로 넘침 없음; 새 게임 진입, 정답 제출, 좌석 메모, FEVER 실행 검증. 좌석 무작위 75건과 순서 무작위 80건은 가능한 전체 배치에서 정답 유일성 확인; 별도 게임별 문제생성 테스트, 80회 도식 정·역 변환 무결성 테스트를 통과했습니다. 개인 휴대폰의 실사용 터치·접근성은 별도 확인이 필요합니다.
